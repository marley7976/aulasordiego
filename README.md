# Aulas do Diego - Web Development 🚀

Este repositório foi criado para armazenar os exercícios e projetos desenvolvidos durante as aulas de desenvolvimento web, cobrindo **HTML**, **Bootstrap (CSS)** e lógica de programação com **JavaScript**.

## 📚 Conteúdo Atual

### 🌐 Estrutura e Estilização (HTML & Bootstrap)
* **index.html**: Estrutura da página "Minha Escola" utilizando o sistema de HTML5 integrado aos contêineres (`container` e `container-fluid`), linhas (`row`) e colunas do Bootstrap 5.

### 💻 Lógica de Programação (JavaScript)
* **arrayas.js**: Exercícios práticos de manipulação de Arrays (listas), laços de repetição (`forEach`) e estruturas de decisão (`if/else`).
* **aual04.js / exercicio.js / renan.js**: Scripts desenvolvidos em aula para fixação de conceitos básicos de JS executados via terminal.

## 🛠️ Tecnologias Utilizadas
* HTML5 (Estruturação)
* Bootstrap 5 / CSS (Estilização e Layout Responsivo)
* JavaScript / Node.js (Lógica e Programação)
