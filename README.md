# Aulas do Diego - Web Development 🚀

Este repositório foi criado para armazenar os exercícios e projetos desenvolvidos durante as aulas de desenvolvimento web, cobrindo **HTML**, **Bootstrap (CSS)** e lógica de programação com **JavaScript**.

## 📚 Conteúdo Atual

### 🌐 Estrutura e Estilização (HTML & Bootstrap)
* **index.html**: Estrutura da página "Minha Escola" utilizando o sistema de HTML5 integrado aos contêineres (`container` e `container-fluid`), linhas (`row`) e colunas do Bootstrap 5.

### 💻 Lógica de Programação Básica e Condicionais (JavaScript)
* **par.impar.js**: Validador de números pares ou ímpares utilizando operadores de resto da divisão.
* **menu.js**: Menu interativo estruturado com `switch/case` para cálculos de áreas e perímetros de formas geométricas.
* **primo.js**: Algoritmo para checagem e identificação de números primos.
* **numeroporextenso.js**: Conversor estruturado de algarismos para escrita por extenso de 1 a 20.
* **media.js / medianota.js**: Algoritmos para cálculo de médias aritméticas, validação de aprovação acadêmica e direitos de recuperação.
* **descontonacompra.js**: Cálculo de descontos progressivos baseados no valor total da compra e quantidade de itens.
* **triangulos.js / imc.js**: Validação de existência de triângulos (equilátero, isósceles e escaleno) e cálculo detalhado de IMC.

### 📊 Estruturas de Dados: Vetores e Matrizes (JavaScript)
* **arrayas.js**: Manipulação de Arrays (listas), laços de repetição (`forEach`), inversão de vetores e buscas dinâmicas.
* **vetores (Exercícios 18 a 24)**: Operações matemáticas entre vetores, ordenação separada de pares e ímpares e comparação de igualdade.
* **matrizes / m3.js (Exercícios M1 a M6)**: Construção de matrizes multidimensionais, extração de diagonal principal, matriz transposta, soma/multiplicação de matrizes e menu interativo para matriz quadrada 4x4.

### 📝 Arquivos de Apoio e Prática
* **naval.js / aual04.js / exercicio.js / renan.js**: Scripts de fixação e códigos desenvolvidos durante as explicações em aula.

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Estruturação Semântica)
* **Bootstrap 5 & CSS3** (Estilização e Layout Responsivo)
* **JavaScript & Node.js** (Lógica de Programação e Algoritmos)
* **Git & GitHub** (Controle de Versão e Documentação)
