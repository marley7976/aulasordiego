# Aulas do Diego - Web Development 🚀

Este repositório foi criado para armazenar os exercícios e projetos desenvolvidos durante as aulas de desenvolvimento web, cobrindo **HTML**, **Bootstrap (CSS)** e lógica de programação com **JavaScript**.

## 📚 Conteúdo Atual

### 🌐 Estrutura e Estilização (HTML & Bootstrap)
* **index.html**: Estrutura da página "Minha Escola" utilizando o sistema de HTML5 integrado aos contêineres (`container` e `container-fluid`), linhas (`row`) e colunas do Bootstrap 5.

### 💻 Lógica de Programação e Exercícios (JavaScript)
* **media.js / medianota.js**: Algoritmos para cálculo de médias aritméticas, validação de aprovação acadêmica e direitos de recuperação (Exercícios 8, 9 e 10).
* **menu.js**: Menu interativo estruturado com `switch/case` para cálculos de áreas e perímetros de formas geométricas (Exercício 3).
* **par.impar.js**: Validador de números pares ou ímpares utilizando operadores de resto da divisão (Exercício 1).
* **primo.js**: Algoritmo para checagem e identificação de números primos (Exercício 5).
* **numeroporextenso.js**: Conversor estruturado de algarismos para escrita por extenso de 1 a 20 (Exercício 7).
* **naval.js**: Scripts de lógica e simulações dinâmicas desenvolvidas em aula (como jogos e automações).
* **arrayas.js**: Exercícios práticos de manipulação de Arrays (listas), laços de repetição (`forEach`) e métodos nativos de modificação.
* **aual04.js / exercicio.js / renan.js**: Scripts de fixação e códigos de apoio desenvolvidos durante as explicações em tempo real.

## 🛠️ Tecnologias Utilizadas
* HTML5 (Estruturação)
* Bootstrap 5 / CSS (Estilização e Layout Responsivo)
* JavaScript / Node.js (Lógica de Programação)
* Git & GitHub (Controle de Versão e Documentação)
